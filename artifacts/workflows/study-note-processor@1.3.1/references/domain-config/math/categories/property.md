# 性质/引理类原子笔记写作规范 (Property/Lemma Note Specification)

## 适用分类

| 子类 | YAML type | Callout |
|------|-----------|---------|
| 性质 | `性质` | `> [!todo] 性质/引理：[名称]` |
| 引理 | `引理` | `> [!todo] 性质/引理：[名称]` |
| 推论 | `推论` | `> [!todo] 性质/引理：[名称]` |

三者共用 Callout `[!todo]`，在 Callout 标题中通过前缀区分（`性质：`、`引理：`、`推论：`）。

## 内容布局（必须按此顺序）

```markdown
---
aliases:
course: {课程名}
type: {性质/引理/推论}
status: 待整理
mastery: {1-5}
date_created: YYYY-MM-DD
tags:
  - 学习笔记
---
# {学术描述性名称}

> [!todo] {性质/引理/推论}：{名称}
> 性质/引理/推论的完整陈述。所有数学符号使用 $\boldsymbol{加粗}$ 与 $\mathrm{直体}$。
> $$ 核心公式（如有） $$

> [!quote]- 证明/推导
> （可选；性质可由定义直接得出时，可不设独立证明节）
> 详细推导过程。

## 理解与细节
- 该性质在整体结构中的位置
- 与相关定理的联系
- 常见误用

## 关联脉络

- **上游依赖**
  - [[前置定义/定理]]
- **下游推导**
  - [[依赖此性质的后续结论]]
- **双链引用**
  - 在 [[所属MOC]] 中被引用
```

## 各节写作要求

### `> [!todo] {性质/引理/推论}：[名称]`

- **性质**：陈述数学对象的内在属性或特征。格式："XX 具有以下性质：..."
- **引理**：陈述为证明某定理服务的辅助命题。若属于某定理的子项，在标题中可点明服务对象
- **推论**：陈述由某定理直接导出的简单结论。通常 ≤ 3 步推理

### `> [!quote]- 证明/推导`（可选）

- **性质**：若性质证明简短（≤ 5 行），可省略独立证明节，在理解段中用一两句话带过
- **引理**：必须有完整证明（它是为某个大定理服务的中间件）
- **推论**：证明应简短，通常标为"由 [[定理名]] 直接可得"

### `## 理解与细节`

- **性质**：该性质为何重要？在什么场景下常用？有无反例说明条件必要性？
- **引理**：说明它在哪个定理的证明中扮演什么角色？它的结论为什么对那个定理至关重要？
- **推论**：解释它和母定理的推理链（一两句话即可），以及该推论的独立使用价值

### `## 关联脉络`

- **上游**：支撑该性质/引理/推论的定义和定理
- **下游**：由它引发的后续结论
- **特别标注**：对于引理，明确标注它服务的**目标定理**
- **特别标注**：对于推论，明确标注它的**母定理**

## 性质 vs 引理 vs 推论的判定

| 判定维度 | 性质 | 引理 | 推论 |
|----------|------|------|------|
| 核心作用 | 描述对象的内在特征 | 为证明大定理服务 | 由定理直接简化得出 |
| 独立引用价值 | 高（多个上下文中使用） | 中低（主要在特定定理的证明中） | 中（可独立使用但推理极短） |
| 证明复杂度 | 低-中 | 中-高 | 极低（≤ 3 步） |
| 典型表述 | "XX 具有以下性质" | "为证明 XX 定理，先证引理" | "由 XX 定理立即可得" |

## 质量检查清单

- [ ] YAML `type` 与内容一致（性质/引理/推论）
- [ ] Callout 标题含正确的类别前缀
- [ ] 命题陈述完整
- [ ] （引理必需，推论建议，性质可选）证明使用 `> [!quote]-` 折叠
- [ ] 理解段覆盖了该命题在体系中的位置
- [ ] 关联脉络含上下游双链
- [ ] 引理标注了目标定理，推论标注了母定理
- [ ] 全文数学符号用 LaTeX 包裹
- [ ] 无编号化名称

# Reference：输出文件模板与命名规范

本文件定义 paper-materializer 的全部输出文件模板。Skill 主体中仅保留素材包概述与引用说明，**详细模板内容以此文件为准**。

运行时应先读取本文件，然后按模板格式填充内容。模板中以 `<...>` 标记的位置需从上游文件中提取实际内容填入。

## 文件组织方式

| 文件 | 内容 |
|:---|:---|
| `p5-模型解释素材_[小问标识].md` | 模型建立段落、参数解读、公式说明 |
| `p5-模型检验素材_[小问标识].md` | 假设检验、残差分析、鲁棒性结论 |
| `p5-图表说明素材_[小问标识].md` | 每张图的标题+描述+发现+关联 |
| `p5-摘要元素材_[小问标识].md` | 问题/方法/结论/创新点各 2–3 句备选 |
| `p5-符号说明素材_[小问标识].md` | 按类别分组的符号表 |
| `p5-模型评价素材_[小问标识].md` | Strengths & Weaknesses 各 2–3 句 |
| `p5-灵敏度分析素材_[小问标识].md` | 参数敏感性描述、稳定性结论 |
| `p5-参考文献素材_[小问标识].md` | GB/T 7714 + APA 双格式引用列表 |

> `[小问标识]` 使用小问编号或名称（如 `q1`、`问题一`），需与上游文档中一致。

## 模板八：参考文献素材（`p5-参考文献素材_[小问标识].md`）

```markdown
# <模型名> 参考文献素材

## 引用原则

- **优先引用**：教材、方法原始论文、经典专著（真实可核实）
- **谨慎引用**：期刊论文（需确保文献真实存在）
- **必须引用**：所有数据来源的官方出处
- **严禁引用**：无法核实的文献、编造的高影响因子论文

## GB/T 7714 格式（国赛适用）

### 奠基文献
[1] 作者. 书名[M]. 出版地: 出版社, 年份.
[2] 作者. 论文标题[J]. 期刊名, 年份, 卷(期): 页码.

### 数据源文献
[3] 国家统计局. <数据集名称>[EB/OL]. 网址, 访问日期.

### 工具文献（如赛题要求）
[4] Van Rossum G, Drake F L. Python 3 Reference Manual[M]. Scotts Valley: CreateSpace, 2009.

## APA 格式（美赛适用）

### 奠基文献
Author, A. A. (Year). *Title of work: Capital letter also for subtitle*. Publisher.

### 数据源文献
National Bureau of Statistics. (Year). *Dataset title*. Retrieved from URL

### 工具文献
Van Rossum, G., & Drake, F. L. (2009). *Python 3 reference manual*. CreateSpace.

---

> **写手使用指南**：
> 1. 删除本模板中的示例条目，填入真实文献

> 3. 不确定真实性的文献宁可不引，也不要编造
> 4. 根据赛题要求选择 GB/T 7714 或 APA 格式，全文统一
```

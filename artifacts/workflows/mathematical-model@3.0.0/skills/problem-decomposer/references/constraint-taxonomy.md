# 约束分类体系（C01-C08）

> problem-decomposer 专用。对小问进行系统化约束扫描时的分类框架。

---

## 约束强度定义

| 强度 | 符号 | 含义 | 处理方式 |
|------|------|------|---------|
| 硬约束 | `[硬]` | 必须严格满足，违反则解无效 | 纳入模型必须条件 |
| 软约束 | `[软]` | 尽量满足，可适当放宽 | 可纳入目标函数（惩罚项）或松弛变量 |

## 八类约束（应用场景视角）

### C01：资源约束

涉及有限资源的分配限制。

- 资金、人力、时间、原材料上限
- 生产能力、存储容量
- **信号词**："不超过""最多""上限""限制在""capacity""budget"
- **数学通式**：$\sum_i w_i x_i \leq W_{\max}$（容量）、$\sum_i c_i x_i \leq B$（预算）

### C02：技术/工艺约束

由物理规律、技术条件、工艺要求决定的限制。

- 化学反应计量关系、能量守恒
- 速度上限、加速度限制
- 精度公差范围
- **信号词**："必须大于""不低于""至少""要求"
- **数学通式**：$x_i \geq L_i$（下限）、$x_i \leq U_i$（上限）

### C03：逻辑/关系约束

变量间的逻辑关系或定义关系。

- 等式定义（如总量 = 分量之和）
- 互斥条件（不能同时选择 A 和 B）→ $x_i + x_j \leq 1$
- 依赖条件（选择了 A 才能选 B）→ $x_A \leq x_B$
- 比例关系
- **信号词**："等于""定义为""由...决定""必须同时""不能同时"
- **注意**：逻辑约束的线性化需要引入辅助变量和大 M 方法，M 取值过大导致数值不稳定

### C04：时间/顺序约束

涉及时序、先后关系、周期性限制。

- 先完成 A 才能开始 B → $t_j \geq t_i + d_i$
- 同一时刻不能做两件互斥的事
- 间隔时间限制（两次操作间至少间隔 T）
- 完工时间窗口
- **信号词**："先...后...""依次""连续""间隔""在...之前/之后"

### C05：空间/几何约束

涉及空间位置、距离、覆盖范围。

- 二维/三维空间范围限制
- 最小/最大距离
- 覆盖半径
- 不可穿越障碍物
- **信号词**："范围内""覆盖""距离""相邻""边界"

### C06：整数/离散约束

变量取值必须是整数或来自离散集合。

- 整数数量（不能有半个人）→ $x_i \in \mathbb{Z}^+$
- 二选一 / 多选一 → $\sum_i y_i = 1,\; y_i \in \{0,1\}$
- 固定选项集合
- **信号词**："整数""若干""选择其一""从...中选取"
- **注意**：整数约束使问题从 LP 变为 MILP/INLP，计算复杂度显著上升。大规模整数问题在竞赛时间内可能不可解，可考虑松弛为连续变量后取整

### C07：政策/规则约束

由法规、政策、行业标准决定的限制。

- 环保标准、排放上限
- 最低工资、劳动法
- 安全标准
- 行业规范
- **信号词**："根据规定""标准要求""符合...法规""不低于国家标准"

### C08：隐含约束

题目未明确写出但实际存在的限制。

- 非负性（数量、时间、距离默认 ≥ 0）
- 概率和为 1
- 比例不超过 100%
- 现实可行性（不可出现负库存等）
- **检测方法**：列出所有变量的定义域，对未声明边界的变量追问"这个变量在现实中能取负值吗？能超过 100% 吗？"

## 约束扫描流程

1. **通读题目原文**，标记所有含信号词的句子
2. **逐句判断约束类型**（C01-C08），填写约束清单
3. **检查遗漏**：
   - 隐含约束：非负、概率和、物理上限
   - 跨小问约束：前面小问的结论是否是后面小问的约束
   - 数据隐含约束：数据中字段的实际取值范围
4. **标注约束强度**：硬约束 / 软约束
5. **一致性检查**：
   - 等式约束是否过约束？等式数是否超过变量数？
   - 不等式约束是否矛盾？（如 x ≥ 5 且 x ≤ 3）
   - 约束间是否存在冗余？

## 附录：数学表达视角的约束分类

> 以下分类从**数学表达形式**的视角重新组织约束，与主分类（C01-C08 应用场景视角）互为补充。
> 在将自然语言约束转化为数学公式时，优先参照此附录。

| 数学类型 | 对应场景类型 | 数学表达通式 | 数模出现频率 |
|:---|:---|:---|:---|
| 等式约束 | C02/C03 | $f(x) = C$ 或 $g(x,y) = h(x,y)$ | 高 |
| 不等式约束 | C01/C02 | $f(x) \leq C$ 或 $f(x) \geq C$ | 高 |
| 整数约束 | C06 | $x_i \in \mathbb{Z}$ 或 $x_i \in \{0,1\}$ | 中高 |
| 互斥约束 | C03 | $x_i + x_j \leq 1$ 或 $\sum_{i \in S} x_i \leq 1$ | 中 |
| 逻辑约束 | C03/C04 | $x_A \leq x_B$ 或 $x_A = 1 \Rightarrow x_B = 1$ | 中 |
| 概率/风险约束 | — | $P(g(x, \xi) \leq 0) \geq \alpha$ | 中低 |
| 动态/递推约束 | C04 | $s_{t+1} = f(s_t, a_t)$ | 中 |
| 边界/初终值条件 | — | $x(0) = x_0$ 或 $x(T) = x_T$ | 中 |

### 数学表达的典型自然语言信号

| 数学类型 | 常见自然语言信号 |
|:---|:---|
| 等式约束 | "总量守恒""收支平衡""等于""恰好""由...定义" |
| 不等式约束 | "不超过""至少""容量限制""不大于""在...范围内" |
| 整数约束 | "必须为整数""整数个""0-1 决策""是否" |
| 互斥约束 | "不能同时""二者择一""排他性""至多选一个""互斥" |
| 逻辑约束 | "若 A 则 B""只有...才...""顺序依赖""优先级" |
| 概率/风险约束 | "置信度不低于""风险阈值""概率不超过""以...的把握" |
| 动态/递推约束 | "状态转移""递推关系""演化规律""下一时刻""随时间变化" |
| 边界/初终值条件 | "初始值为""边界处为""起始状态""终点要求""在 t=0 时" |

### 建模注意要点

- **等式约束**：过强可能导致可行域退化甚至为空，需检查一致性；多个等式约束可能隐式消除变量
- **不等式约束**：严格不等式 $>$ vs 非严格不等式 $\geq$ 在优化中处理方式不同；上下界可合并为盒约束
- **整数约束**：大规模整数问题在竞赛时间内可能不可解，需评估问题规模，考虑松弛或启发式
- **互斥约束**：大量互斥约束可能导致可行域碎片化，通常与整数约束配合使用
- **逻辑约束**：线性化需引入辅助变量和大 M 方法；注意 $M$ 取值——过大导致数值不稳定，过小导致约束无效
- **概率约束**：若缺乏概率分布信息，常用情景分析法或蒙特卡洛模拟替代
- **动态约束**：需明确时间/空间步长、状态维度、控制维度；初值条件通常与动态约束配套出现
- **边界条件**：初值+动态约束构成初值问题（IVP），边界+动态约束构成边值问题（BVP）；注意边值问题的适定性

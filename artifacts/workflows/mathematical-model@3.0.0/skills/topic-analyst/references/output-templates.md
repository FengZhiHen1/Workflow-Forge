## P1a：各选题独立分析模板

文件路径：`GLOBAL_SHARED/P1a-选题分析_题X.md`

> 结构同上方的"P1a 选题分析模板"，逐题生成独立文件。歧义分析仅生成一次（全局文件），不在各题独立分析中重复。

---

## 使用说明

1. **歧义分析**先于选题分析执行，作为硬门控——高危歧义必须人工确认后才能继续后续分析
2. **单选题**：只生成 `P1a-歧义分析.md` + `P1a-选题分析.md`
3. **多选题**：额外生成 `P1a-多选题对比分析.md` + 各题 `P1a-选题分析_题X.md`
4. 所有文档开头必须包含版本记录表
5. 所有产出写入 `GLOBAL_SHARED`（即 `workspace/shared/`）

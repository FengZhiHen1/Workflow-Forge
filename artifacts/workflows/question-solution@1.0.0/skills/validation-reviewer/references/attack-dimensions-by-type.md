# Reference：按问题类型分类的攻击维度与致命性阈值

本文件按 `problem_type` 提供差异化的攻击维度清单和量化致命性阈值。在 P4-对抗阶段，根据被审查小问的问题类型，加载对应的攻击维度进行针对性审查。

---

## 通用攻击维度（所有类型适用）

以下攻击维度适用于所有问题类型，是 P4-对抗的基础检查：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| G01 | 边界攻击 | 极端输入下模型是否失效（全0、全缺失、边界值） |
| G02 | 假设攻击 | 假设的失效条件、隐式假设、与题目条件的矛盾 |
| G03 | 鲁棒性攻击 | 参数扰动5%后结果变化、过度敏感特征 |
| G04 | 自我矛盾攻击 | 公式推导与代码实现是否一致、跨文档符号/假设自洽 |
| G05 | 赛题覆盖攻击 | 是否回答了赛题的每一个提问、隐含要求是否被忽略 |
| G06 | 论文呈现攻击 | 结果/敏感性/假设/创新性/局限性的论文呈现质量 |

## 按问题类型的专属攻击维度

### 1. 优化问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| OPT-01 | 最优性攻击 | 下界/上界 Gap、对偶间隙、松弛紧致性 |
| OPT-02 | 可行性攻击 | 求解器返回的解是否满足所有硬约束 |
| OPT-03 | 收敛性攻击 | 启发式算法是否收敛到稳定解、收敛速度 |
| OPT-04 | 尺度攻击 | 问题规模扩大后（变量/约束数增加）求解时间是否可接受 |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①求解器报告"不可行"或解不满足硬约束 ②Gap > 40% 且无收紧路径 ③对偶间隙 > 30% ④算法不收敛或陷入局部最优无法跳出 |
| 🟡 高危 | ①Gap 20%-40% ②对偶间隙 10%-30% ③求解时间超过赛程可接受范围（>30分钟）④小规模实例上即出现数值不稳定 |
| 🟢 提示 | ①可视化可更丰富 ②可补充更多敏感性测试 ③论文中可加强最优性论证 |

---

### 2. 预测/时序问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| PRD-01 | 外推稳定性攻击 | 超出训练数据范围的预测是否合理、是否发散 |
| PRD-02 | 过拟合攻击 | 训练集表现远好于测试集、模型复杂度与数据量不匹配 |
| PRD-03 | 数据泄漏攻击 | 训练集与测试集是否存在信息交叉、特征工程是否用了未来信息 |
| PRD-04 | 残差诊断攻击 | 残差是否独立、同方差、正态；是否存在自相关 |
| PRD-05 | 基准对比攻击 | 与简单基准模型（如朴素预测、移动平均）的对比是否充分 |
| PRD-06 | 区间预测攻击 | 是否提供了预测区间/置信区间、区间覆盖率是否可靠 |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①MAPE > 30% 或 RMSE 超过基准模型 2 倍 ②存在数据泄漏 ③外推时预测值发散或出现明显不合理趋势 ④残差存在严重自相关或异方差且未处理 |
| 🟡 高危 | ①MAPE 10%-30% ②训练/测试差距 > 20% ③未与基准模型对比 ④未提供预测区间 ⑤模型复杂度远高于数据量支撑 |
| 🟢 提示 | ①可补充交叉验证 ②可视化可更丰富 ③可尝试更多特征工程 |

---

### 3. 分类问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| CLS-01 | 准确率陷阱攻击 | 在不平衡数据上高准确率是否只是预测了多数类 |
| CLS-02 | 混淆矩阵攻击 | 是否提供了混淆矩阵、各类别的精确率/召回率/F1 |
| CLS-03 | ROC-AUC 可靠性攻击 | AUC 是否被极端类别主导、PR 曲线是否更可靠 |
| CLS-04 | 类别不平衡攻击 | 是否处理了类别不平衡（重采样/代价敏感） |
| CLS-05 | 决策边界攻击 | 决策边界是否过于复杂（过拟合）或过于简单（欠拟合） |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①准确率 ≈ 多数类占比（基准陷阱）②F1 < 0.3 ③存在数据泄漏 ④未处理严重类别不平衡（最小类占比 < 5%） |
| 🟡 高危 | ①F1 0.3-0.6 ②召回率/精确率严重失衡（>3:1）③未提供混淆矩阵 ④仅在单一训练/测试划分上评估 |
| 🟢 提示 | ①可补充交叉验证 ②可尝试集成方法 ③可补充特征重要性分析 |

---

### 4. 回归/统计推断问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| REG-01 | 多重共线性攻击 | VIF 是否过高、相关矩阵是否存在 |r| > 0.8 |
| REG-02 | 异方差攻击 | 残差是否存在异方差、是否使用了稳健标准误 |
| REG-03 | 自相关攻击 | 残差是否存在时间/空间自相关、Durbin-Watson 检验 |
| REG-04 | 杠杆点/强影响点攻击 | 是否存在高杠杆点对回归线产生过大影响 |
| REG-05 | 模型设定攻击 | 函数形式是否正确（线性 vs 非线性）、遗漏变量问题 |
| REG-06 | 统计显著性攻击 | 关键系数是否统计显著、置信区间是否过宽 |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①$R^2 < 0.3$ ②存在严重异方差且未处理 ③VIF > 10 且未处理 ④关键系数不显著（p > 0.1）⑤残差严重自相关且未处理 |
| 🟡 高危 | ①$R^2$ 0.3-0.6 ②VIF 5-10 ③存在轻微异方差 ④置信区间较宽 ⑤遗漏变量嫌疑 |
| 🟢 提示 | ①可补充残差诊断图 ②可尝试变换（对数/Box-Cox）③可补充影响点分析 |

---

### 5. 微分方程问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| ODE-01 | 适定性攻击 | 解的存在性、唯一性、连续依赖性是否成立 |
| ODE-02 | 数值稳定性攻击 | 时间步长是否合适、是否出现数值振荡/发散 |
| ODE-03 | 参数可辨识性攻击 | 参数是否可从数据中唯一确定、是否存在参数相关性 |
| ODE-04 | 刚性攻击 | 问题是否为刚性问题、是否需要刚性求解器 |
| ODE-05 | 守恒量攻击 | 数值解是否保持物理守恒量（质量/能量/动量） |
| ODE-06 | 解析验证攻击 | 在可解析求解的简化情形下，数值解与解析解是否一致 |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①数值解发散或出现非物理振荡 ②参数不可辨识 ③解析验证时相对误差 > 20% ④守恒量误差 > 10% ⑤使用了不合适的求解器导致数值不稳定 |
| 🟡 高危 | ①相对误差 5%-20% ②时间步长可能偏大（CFL条件临界）③参数辨识存在轻微相关性 ④数值解在某些区域精度不足 |
| 🟢 提示 | ①可补充不同时间步长的收敛性测试 ②可补充守恒量监控 ③可尝试更高阶数值格式 |

---

### 6. 网络/图论问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| NET-01 | 连通性攻击 | 图是否连通、是否存在孤立节点、连通分量分析 |
| NET-02 | 算法近似比攻击 | 启发式算法的解与最优解的差距、近似比是否有理论保证 |
| NET-03 | 复杂度攻击 | 算法时间复杂度、在大规模图上是否可运行 |
| NET-04 | 社区结构攻击 | 社区发现结果是否稳定、不同算法结果是否一致 |
| NET-05 | 鲁棒性攻击 | 删除部分节点/边后网络性质是否剧变 |
| NET-06 | 传播模型攻击 | 传播模型参数是否经过校准、模型预测是否合理 |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①算法在竞赛时间内无法完成（>30分钟）②近似比无保证且 Gap > 50% ③图结构存在致命缺陷（如核心节点缺失）④传播模型预测与常识严重矛盾 |
| 🟡 高危 | ①大规模图上运行时间临界 ②近似比 Gap 20%-50% ③社区发现结果不稳定 ④网络鲁棒性较差 |
| 🟢 提示 | ①可补充不同算法的对比 ②可补充可视化 ③可尝试更高效的算法 |

---

### 7. 综合评价/多属性决策问题

**专属攻击维度**：

| 编号 | 攻击维度 | 检查要点 |
|:---|:---|:---|
| EVA-01 | 权重敏感性攻击 | 权重扰动 10% 后排序是否剧变 |
| EVA-02 | 指标冗余攻击 | 指标间是否存在高度相关（冗余指标） |
| EVA-03 | 排序稳定性攻击 | 移除单个评价对象后整体排序是否剧变 |
| EVA-04 | 权重方法偏差攻击 | 主观赋权 vs 客观赋权结果是否差异过大 |
| EVA-05 | 数据标准化攻击 | 不同标准化方法（min-max/z-score）是否导致不同结论 |
| EVA-06 | 阈值敏感性攻击 | 分类阈值变化是否导致评价等级剧变 |

**致命性阈值**：

| 等级 | 判定标准 |
|:---|:---|
| 🔴 致命 | ①权重扰动 10% 导致排序变化 > 3 位 ②主观/客观赋权结果完全矛盾（Spearman 相关系数 < 0.3）③不同标准化方法导致结论相反 ④存在严重指标冗余但未处理 |
| 🟡 高危 | ①排序变化 1-3 位 ②存在中度指标冗余 ③权重方法偏差中等 ④阈值敏感性较高 |
| 🟢 提示 | ①可补充敏感性分析可视化 ②可尝试组合赋权 ③可补充指标筛选（PCA/因子分析） |

---

## 使用指南

在 P4-对抗阶段：

1. 从 P1b-小问分析文档中读取 `problem_type`
2. 执行通用攻击维度 G01-G06
3. 根据 problem_type 加载对应的专属攻击维度（OPT/PRD/CLS/REG/ODE/NET/EVA）
4. 按致命性阈值进行量化判定
5. 若 problem_type 不明确或属于混合类型，执行所有相关类型的专属维度交集

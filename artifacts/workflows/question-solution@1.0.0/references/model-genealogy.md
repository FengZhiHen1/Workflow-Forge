# 模型族谱速查

> 按 7 类标准问题类型组织的候选模型族。topic-analyst（宏观选型）和 problem-decomposer（小问级算法推荐）共用此分类体系。
> 原则：提供**模型族谱**（模型之间的演进关系和适用场景），避免幻觉风险。

---

## 七类标准问题类型

| 类型 | 英文 | 核心特征 | 典型输出 |
|------|------|---------|---------|
| 优化 | Optimization | 目标函数 + 约束条件，求极值 | 最优解、对偶间隙、灵敏度 |
| 预测 | Prediction | 时间序列或因果关系，推断未来 | 预测值、置信区间、误差指标 |
| 分类 | Classification | 离散标签，判别归属 | 类别、概率、混淆矩阵 |
| 回归 | Regression | 连续输出，变量关系建模 | 系数估计、拟合优度、残差诊断 |
| 微分方程 | Differential Equations | 动态系统，连续变化率 | 数值解、稳定性、相图 |
| 网络 | Network / Graph | 节点与边，拓扑结构 | 路径、流量、中心性 |
| 综合评价 | Comprehensive Evaluation | 多指标聚合，排序决策 | 评分、权重、排序、敏感性 |

## 1. 优化问题

```
线性规划 (LP)
├── 整数线性规划 (ILP) ──> 混合整数线性规划 (MILP)
│   └── 0-1 规划 ──> 指派问题、背包问题、覆盖问题
├── 多目标优化 ──> 帕累托前沿、加权法、ε-约束法
│   └── 层次分析法 (AHP) ──> 熵权法、TOPSIS
└── 非线性规划 (NLP)
    ├── 凸优化 ──> 二次规划 (QP)、半定规划 (SDP)
    └── 启发式算法
        ├── 遗传算法 (GA)
        ├── 模拟退火 (SA)
        ├── 粒子群优化 (PSO)
        └── 禁忌搜索 (TS)
```

| 子类 | 候选模型 | 求解方法 | 适用规模 |
|------|---------|---------|---------|
| 线性规划 | LP | 单纯形法、内点法 | 大规模 |
| 整数规划 | ILP / MILP | 分支定界、割平面 | 中小规模 |
| 非线性规划 | NLP | 梯度下降、内点法、SQP | 中规模 |
| 组合优化 | TSP 模型、背包模型 | 动态规划、分支定界、启发式 | 小规模精确 / 大规模启发式 |
| 多目标优化 | 加权法、Pareto、目标规划 | 标量化后求解 | 中规模 |

**选择指南**：
- 目标函数和约束均为线性 → LP
- 含整数/0-1 决策变量 → ILP/MILP
- 多个冲突目标 → 多目标优化 / AHP+TOPSIS
- 问题规模大、结构复杂 → 启发式算法
- 需严格最优解且规模可控 → 精确算法（分支定界、割平面）

## 2. 预测/时序问题

```
时间序列分析
├── 经典方法
│   ├── 移动平均 (MA)
│   ├── 指数平滑 (ES) ──> Holt-Winters（含趋势+季节）
│   └── ARIMA 族 ──> SARIMA（季节性）、ARIMAX（含外生变量）
├── 状态空间模型
│   └── 卡尔曼滤波 ──> 扩展卡尔曼滤波、粒子滤波
├── 机器学习方法
│   ├── 回归树 / 随机森林 / XGBoost
│   ├── 神经网络
│   │   ├── 全连接网络 (MLP)
│   │   ├── 循环神经网络 (RNN/LSTM/GRU)
│   │   └── 注意力机制 / Transformer
│   └── 集成方法 ──> Stacking、Boosting
└── 灰色预测 ──> GM(1,1)、灰色 Verhulst
```

| 子类 | 候选模型 | 数据需求 | 预测窗口 |
|------|---------|---------|---------|
| 时间序列 | ARIMA / SARIMA | ≥30 观测、≥2 完整周期 | 短期 |
| 指数平滑 | Holt-Winters | ≥2 完整周期 | 短期 |
| 灰色预测 | GM(1,1) | ≥4 观测 | 短期 |
| 机器学习 | XGBoost, LightGBM, LSTM | 大量样本、多特征 | 中短期 |
| 回归预测 | 多元线性回归 + 时间特征 | 至少 10k 样本（k 为特征数） | 中期 |

**选择指南**：
- 数据量小(<50)、趋势明显 → GM(1,1) / 指数平滑
- 数据量中等、有季节性 → SARIMA / Holt-Winters
- 数据量大、多变量 → XGBoost / LSTM / Transformer
- 有状态转移结构 → 卡尔曼滤波 / HMM
- 短期预测、高频数据 → ARIMA / LSTM

## 3. 分类问题

```
分类方法
├── 经典统计方法
│   ├── 逻辑回归 (Logistic Regression)
│   ├── 线性判别分析 (LDA) / 二次判别分析 (QDA)
│   └── 朴素贝叶斯 (Naive Bayes)
├── 机器学习方法
│   ├── 决策树 ──> 随机森林、XGBoost、LightGBM
│   ├── 支持向量机 (SVM) ──> 核 SVM
│   ├── K 近邻 (KNN)
│   └── 神经网络
│       ├── MLP
│       └── 卷积神经网络 (CNN) ──> ResNet
└── 集成与提升
    ├── Bagging ──> 随机森林
    ├── Boosting ──> AdaBoost、GBDT、XGBoost
    └── 堆叠 (Stacking)
```

| 子类 | 候选模型 | 优点 | 注意 |
|------|---------|------|------|
| 经典统计 | 逻辑回归、LDA | 可解释性强 | 线性边界假设 |
| 树模型 | 决策树、随机森林 | 非线性、特征重要性 | 过拟合风险 |
| 支持向量机 | SVM | 高维有效 | 核函数选择 |
| 深度学习 | MLP, CNN | 自动特征提取 | 大量数据需求 |

**选择指南**：
- 需要可解释性 → 逻辑回归 / 决策树
- 高维数据 → SVM / 神经网络
- 数据量大 → XGBoost / LightGBM
- 类别不平衡 → 代价敏感学习 / SMOTE + 集成方法
- 图像/文本数据 → CNN / Transformer

## 4. 回归/统计推断问题

```
回归分析
├── 线性回归族
│   ├── 普通最小二乘 (OLS)
│   ├── 岭回归 (Ridge) ──> LASSO ──> 弹性网络 (Elastic Net)
│   ├── 主成分回归 (PCR)
│   └── 偏最小二乘 (PLS)
├── 广义线性模型 (GLM)
│   ├── 泊松回归（计数数据）
│   └── Gamma 回归（正值连续数据）
├── 非参数/半参数方法
│   ├── 局部加权回归 (LOESS)
│   ├── 样条回归 (Spline)
│   └── 核回归
├── 机器学习方法
│   ├── 回归树 / 随机森林 / XGBoost
│   └── 神经网络 (MLP)
└── 面板数据方法
    ├── 固定效应模型
    ├── 随机效应模型
    └── 动态面板 (GMM)
```

| 子类 | 候选模型 | 关键假设 | 诊断工具 |
|------|---------|---------|---------|
| 线性回归 | OLS | 线性、独立、正态、同方差 | VIF、DW、QQ 图 |
| 正则化回归 | Ridge, LASSO, ElasticNet | 同上 + 稀疏性 | 交叉验证选 λ |
| 非线性回归 | 多项式、指数、对数变换 | 指定函数形式 | 残差图 |
| 稳健回归 | Huber, 分位数回归 | 放宽正态/同方差 | 影响函数 |
| 非参数回归 | GAM, LOESS, KNN | 最小假设 | 维度灾难 |

**选择指南**：
- 经典线性关系、解释为主 → OLS
- 多重共线性严重 → 岭回归 / PCR / PLS
- 变量选择需求 → LASSO / 弹性网络
- 非线性关系明显 → 样条 / XGBoost / 神经网络
- 面板数据 → 固定/随机效应 + Hausman 检验
- 异方差/自相关 → 稳健标准误 / GLS / GMM

## 5. 微分方程问题

```
微分方程建模
├── 常微分方程 (ODE)
│   ├── 解析方法 ──> 分离变量、特征方程、拉普拉斯变换
│   └── 数值方法
│       ├── 欧拉法
│       ├── Runge-Kutta 法（RK4）
│       └── 多步法（Adams-Bashforth）
├── 偏微分方程 (PDE)
│   ├── 解析方法 ──> 分离变量、傅里叶变换
│   └── 数值方法
│       ├── 有限差分法 (FDM)
│       ├── 有限元法 (FEM)
│       └── 有限体积法 (FVM)
├── 差分方程
│   └── 离散动力系统 ──> 迭代法、不动点分析
└── 随机微分方程 (SDE)
    └── Euler-Maruyama 方法
```

| 子类 | 候选模型 | 数值方法 | 关键检查 |
|------|---------|---------|---------|
| ODE | 常微分方程组 | Euler, Runge-Kutta 4/5 | 适定性、刚性 |
| PDE | 扩散方程、波动方程 | 有限差分、有限元 | 稳定性条件（CFL） |
| 传染病 | SIR 及变体 | ODE 数值求解 | 参数可辨识性 |
| 种群动力学 | Lotka-Volterra | ODE 数值求解 | 平衡点稳定性 |

**选择指南**：
- 一维时间演化、光滑解 → 解析方法 + RK4
- 多维空间+时间、复杂几何 → 有限差分 / 有限元
- 稳定性分析需求 → 特征方程 + Lyapunov 指数
- 含随机扰动 → SDE + Euler-Maruyama
- 参数未知 → 参数辨识（最小二乘 / 贝叶斯）

## 6. 网络/图论问题

```
图论与网络分析
├── 经典图论算法
│   ├── 最短路径 ──> Dijkstra、Floyd-Warshall、Bellman-Ford
│   ├── 最小生成树 ──> Prim、Kruskal
│   ├── 最大流/最小割 ──> Ford-Fulkerson、Edmonds-Karp、Dinic
│   └── 匹配 ──> 匈牙利算法
├── 网络优化
│   ├── 旅行商问题 (TSP) ──> 精确算法 / 启发式（遗传、蚁群）
│   ├── 车辆路径问题 (VRP) ──> 启发式 / 元启发式
│   └── 网络设计 ──> 斯坦纳树、设施选址
├── 复杂网络分析
│   ├── 社区发现 ──> Louvain、谱聚类
│   ├── 中心性分析 ──> 度中心性、介数中心性、特征向量中心性
│   └── 网络传播 ──> SIR/SIS 模型、级联模型
└── 图神经网络 (GNN)
    └── GCN、GAT、GraphSAGE
```

| 子类 | 候选模型 | 算法 | 复杂度 |
|------|---------|------|--------|
| 最短路径 | Dijkstra, Floyd-Warshall | 图搜索 | O(V²) - O(V³) |
| 最大流 | Ford-Fulkerson, Dinic | 增广路 | O(VE²) - O(V²E) |
| 最小生成树 | Kruskal, Prim | 贪心 | O(E log V) |
| 网络流 | 费用流、多商品流 | LP/ILP 松弛 | NP-hard（多商品） |
| 中心性分析 | PageRank, Betweenness | 迭代/路径计数 | O(V³) |

**选择指南**：
- 经典路径/流/匹配问题 → 多项式时间精确算法
- NP-hard 组合优化 → 启发式 / 元启发式
- 网络结构分析 → 中心性 + 社区发现
- 动态过程（传播/级联）→ SIR / 级联模型
- 图结构+节点特征 → GNN

## 7. 综合评价/多属性决策问题

```
评价与决策方法
├── 权重确定
│   ├── 主观方法 ──> AHP、德尔菲法
│   ├── 客观方法 ──> 熵权法、CRITIC、变异系数法
│   └── 组合赋权 ──> 乘法合成、线性组合
├── 评价模型
│   ├── TOPSIS ──> 改进 TOPSIS
│   ├── 灰色关联分析 (GRA)
│   ├── 模糊综合评价
│   ├── 数据包络分析 (DEA)
│   └── 主成分分析 (PCA) / 因子分析
└── 排序与分类
    ├── 秩和比 (RSR)
    ├── 聚类分析 ──> K-means、层次聚类、DBSCAN
    └── 多维标度 (MDS)
```

| 子类 | 候选模型 | 权重来源 | 敏感性 |
|------|---------|---------|--------|
| 层次分析 | AHP | 成对比较矩阵 | 判断矩阵一致性 |
| 熵权法 | Entropy-TOPSIS | 数据驱动 | 指标分布 |
| 模糊评价 | Fuzzy Comprehensive | 隶属函数 + 权重 | 隶属函数参数 |
| 灰色关联 | GRA | 参考序列选择 | 分辨系数 ρ |
| 组合评价 | CRITIC-TOPSIS, VIKOR | 数据 + 偏好 | 方法间一致性 |

**选择指南**：
- 有明确的指标体系 → TOPSIS / GRA / 模糊评价
- 投入产出效率 → DEA
- 权重需要主客观结合 → AHP+熵权法组合
- 数据降维需求 → PCA / 因子分析
- 无标签分类 → 聚类分析

## 模型选择快速对照表

| 场景特征 | 首选模型族 | 备选模型族 | 关键考量 |
|:---|:---|:---|:---|
| 小规模、线性、精确解 | LP / 解析 ODE | 启发式 | 计算时间 |
| 大规模、组合爆炸 | 启发式（GA/PSO/SA） | 精确算法（分支定界） | 解的质量 vs 时间 |
| 时间序列、有季节性 | SARIMA / Holt-Winters | Prophet / LSTM | 可解释性 vs 精度 |
| 多变量预测、非线性 | XGBoost / LSTM | 随机森林 / ARIMAX | 特征重要性 |
| 需要强可解释性 | 线性回归 / 逻辑回归 / AHP | 决策树 | 模型复杂度 |
| 高维小样本 | 岭回归 / LASSO / SVM | PCR / PLS | 过拟合风险 |
| 网络结构问题 | 图算法 / 网络流 | GNN | 问题规模 |
| 多目标冲突 | 帕累托优化 / AHP+TOPSIS | 加权法 | 决策者偏好 |

## 选型准则

1. **数据驱动优先**：先看有什么数据，再决定能用什么模型
2. **简单优先**：能线性不非线性，能统计不 ML，能经典不创新
3. **可解释性要求**：竞赛论文需解释模型，黑箱模型需额外论证
4. **时间约束**：赛程时间决定模型复杂度上限
5. **降级链**：每个选型必须有备选方案，形成"主 → 备选 → 降级"链

---

## Fallback 策略

当主模型因数据或时间限制无法使用时，按以下优先级选择备选：

1. **数据不足** → 简化模型（如神经网络 → 线性回归，MILP → LP）
2. **计算超时** → 启发式算法替代精确算法
3. **假设不满足** → 非参数方法替代参数方法（如核回归替代线性回归）
4. **维度灾难** → 降维 + 简单模型（PCA + 线性回归）
5. **模型失败** → 集成方法 / 模型平均

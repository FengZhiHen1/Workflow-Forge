# 数学领域格式契约 (Format Contract)

> 本文件定义数学领域特有的格式规则。
>
> **通用 Obsidian 格式规则**（frontmatter 结构、双链、标题层级、列表、表格嵌套、高亮避让、文本格式化）见 `references/obsidian-format-rules.md`。

## 文件 Frontmatter 规范（数学领域）

通用 frontmatter 结构见 `obsidian-format-rules.md`。数学领域的 `type` 取值如下：

| type 值 | 说明 |
|---------|------|
| 书MOC / 节MOC | MOC 文件 |
| 定义 | 定义类原子笔记 |
| 定理 | 定理/公理类原子笔记 |
| 性质 | 性质类原子笔记 |
| 引理 | 引理类原子笔记 |
| 推论 | 推论类原子笔记 |
| 方法 | 方法类原子笔记 |
| 反例 | 反例类原子笔记 |

## Callout 映射表

所有数学内容必须使用 Obsidian 原生 Callout，映射关系如下：

| 数学要素 | Callout 语法 | 折叠 |
|----------|-------------|------|
| 定义 | `> [!abstract] 定义：[名称]` | 否 |
| 定理 / 公理 | `> [!info] 定理/公理：[名称]` | 否 |
| 性质 / 引理 | `> [!todo] 性质/引理：[名称]` | 否 |
| 方法 | `> [!info] 方法：[名称]` | 否 |
| 补充 / 注意 | `> [!tip] 补充/注意` | 否 |
| 证明 | `> [!quote]- 证明` | **是**（`-` 表示默认折叠） |
| 例题 | `> [!example]- 例题` | **是** |
| 重难点预警 | `> [!warning] 易错点/重难点` | 否 |
| 反例 | `> [!warning] 反例` | 否 |
| 逻辑脉络（MOC 专用） | `> [!abstract]- 逻辑脉络图景` | **是** |

**铁律**：
- 证明和例题**必须折叠**（`-` 后缀），其他 Callout 默认展开
- Callout 标题必须包含类别标识（如 `定义：`、`定理/公理：`）
- 一个 Callout 只对应一个数学要素，禁止合并

## LaTeX 规范

### 基本要求

1. **全量包裹**：所有数学符号、变量、表达式必须用 `$...$`（行内）或 `$$...$$`（行间）包裹。严禁裸写数学字母或符号。
2. **变量加粗**：矩阵、向量、变量统一使用 `\boldsymbol{}` 加粗。
   - 示例：`$\boldsymbol{x}$`、`$\boldsymbol{A}$`、`$\boldsymbol{\alpha}$`
3. **直体规范**：微分符号、数学常数、虚数单位必须使用 `\mathrm{}` 去除斜体。
   - 示例：`$\mathrm{d}x$`、`$\mathrm{e}$`、`$\mathrm{i}$`
4. **数字规则**：除作为"编号"或"量词"的数字外，所有"数学对象"数字必须用公式块包裹。

### 排版格式

1. **行间公式间距**：`$$...$$` 与前后文字之间**必须各留 1 个空格**。
2. **标点间隔**：公式与末尾标点符号之间**无间隔**（公式和逗号/句号紧贴）。
3. **逻辑量词**：优先使用标准符号 `$\forall$`、`$\exists$`、`$\implies$`、`$\iff$`。

### 编号规则

1. 无关编号的数字无需公式包裹：`经过 2 步推导`（2 是编号）
2. 数学数字必须包裹：`当 $x = 2$ 时`（2 是数学对象）

# Obsidian 格式契约 (Format Contract)

## 文件 Frontmatter 规范

每个 MOC 文件（书级/节级）和原子笔记 .md 文件必须包含 YAML frontmatter：

```yaml
---
aliases:             # （可选）双链别名
course: {课程名}      # 课程/教材名
type: {类型}          # 书MOC / 节MOC / 定义 / 定理 / 性质 / 引理 / 推论 / 方法 / 反例
status: 待整理        # 状态：待整理 / 已整理 / 需复习
mastery: {1-5}       # 掌握程度：1-5
date_created: YYYY-MM-DD
tags:
  - 学习笔记
---
```

## Callout 映射表

所有数学内容必须使用 Obsidian 原生 Callout，映射关系如下：

| 数学要素 | Callout 语法 | 折叠 |
|----------|-------------|------|
| 定义 | `> [!abstract] 定义：[名称]` | 否 |
| 定理 / 公理 | `> [!info] 定理/公理：[名称]` | 否 |
| 性质 / 引理 | `> [!todo] 性质/引理：[名称]` | 否 |
| 方法 | `> [!info] 方法：[名称]` | 否 |
| 补充 / 注意 | `> [!tip] 补充/注意` | 否 |
| 证明 | `> [!quote]- 证明` | **是**（`-` 表示默认折叠） |
| 例题 | `> [!example]- 例题` | **是** |
| 重难点预警 | `> [!warning] 易错点/重难点` | 否 |
| 反例 | `> [!warning] 反例` | 否 |
| 逻辑脉络（MOC 专用） | `> [!abstract]- 逻辑脉络图景` | **是** |

**铁律**：
- 证明和例题**必须折叠**（`-` 后缀），其他 Callout 默认展开
- Callout 标题必须包含类别标识（如 `定义：`、`定理/公理：`）
- 一个 Callout 只对应一个数学要素，禁止合并

## 双链规范 (`[[]]`)

### 基本规则

1. **双链名称 = 文件名（不含 .md 扩展名）**
2. MOC 文件中，原子点使用列表形式罗列双链：
   ```markdown
   - [[原子点 1]]：15-30 字概述
       - [[从属原子点]]：概述
   ```
3. 原子笔记文件中，在"关联脉络"节使用 `- [[上游笔记]]` / `- [[下游笔记]]` 列出关联

### 外部引用标注

- 引用非本课程资源：`[[路径/文件名|显示名]]`
- 引用网页资源：`[显示名](URL)`
- 引用教材页码：正文中标注，如 `（教材 P.123）`

## LaTeX 规范

### 基本要求

1. **全量包裹**：所有数学符号、变量、表达式必须用 `$...$`（行内）或 `$$...$$`（行间）包裹。严禁裸写数学字母或符号。
2. **变量加粗**：矩阵、向量、变量统一使用 `\boldsymbol{}` 加粗。
   - 示例：`$\boldsymbol{x}$`、`$\boldsymbol{A}$`、`$\boldsymbol{\alpha}$`
3. **直体规范**：微分符号、数学常数、虚数单位必须使用 `\mathrm{}` 去除斜体。
   - 示例：`$\mathrm{d}x$`、`$\mathrm{e}$`、`$\mathrm{i}$`
4. **数字规则**：除作为"编号"或"量词"的数字外，所有"数学对象"数字必须用公式块包裹。

### 排版格式

1. **行间公式间距**：`$$...$$` 与前后文字之间**必须各留 1 个空格**。
2. **标点间隔**：公式与末尾标点符号之间**无间隔**（公式和逗号/句号紧贴）。
3. **逻辑量词**：优先使用标准符号 `$\forall$`、`$\exists$`、`$\implies$`、`$\iff$`。

### 编号规则

1. 无关编号的数字无需公式包裹：`经过 2 步推导`（2 是编号）
2. 数学数字必须包裹：`当 $x = 2$ 时`（2 是数学对象）

## 高亮避让原则

**严格禁止**将包含 `$` 符号的公式块包裹在 `==...==` 高亮语法内，这会导致 Obsidian 渲染崩溃。

- 正确：`==级数收敛== 等价于 $\lim_{n \to \infty} \boldsymbol{S}_n$ 存在`
- 错误：`==级数收敛等价于 $\lim_{n \to \infty} \boldsymbol{S}_n$ 存在==`
- 补救：只高亮公式前的术语文字，公式本身不高亮

## 标题层级规范

### MOC 文件

| 层级 | 用途 | 示例 |
|------|------|------|
| `#` H1 | 节 MOC 标题（文件名） | `# MOC-1.1 常数项级数的概念与基本性质` |
| `##` H2 | 逻辑模块名（纯文本，不用编号） | `## 常数项级数的概念与基本性质` |

### 原子笔记文件

| 层级 | 用途 | 示例 |
|------|------|------|
| `#` H1 | 笔记标题（文件名） | `# 常数项无穷级数定义` |
| `##` H2 | 平级延伸模块 | `## 理解与细节`、`## 关联脉络` |
| `###` H3 | 细分推导步骤 | `### 部分和的单调性` |

**铁律**：原子笔记中禁止使用 H1 以外的标题作为"主标题"（文件名即为标题，H1 应复现它）。

## 列表规范

- **并列性质/分类**：使用无序列表 `- `
- **逻辑步骤**：使用有序列表 `1. `
- **从属缩进**：必须使用严格 4 格空格缩进（不可用 Tab）

## 文本格式化

- **核心术语/结论首次出现**：使用 `==高亮==` 标注
- **重要推导节点**：使用 `**加粗**`
- **正文标点**：非公式部分统一使用中文全角标点

# 方法类原子笔记写作规范 (Method Note Specification)

## 适用分类

YAML `type: 方法`，Callout `> [!info] 方法：[名称]`。

> 方法类笔记与定理/性质类笔记的不同在于：它强调**操作流程**和**适用条件**，而非理论命题。

## 内容布局（必须按此顺序）

```markdown
---
aliases:
course: {课程名}
type: 方法
status: 待整理
mastery: {1-5}
date_created: YYYY-MM-DD
tags:
  - 学习笔记
---
# {学术描述性名称}

> [!info] 方法：{名称}
> 方法的一句话概括：用于解决什么问题，核心思路是什么。

## 适用条件
- 条件 1：...
- 条件 2：...
- （明确列出使用该方法前必须验证的所有前提）

## 方法步骤
1. 第一步...
2. 第二步...
3. 第三步...
（有序列表，严格按执行顺序编号）

> [!tip] 补充/注意
> - 关键注意事项
> - 与相似方法的对比
> - 常见错误

> [!example]- 例题
> 具体计算实例。展示方法的完整应用。
> 包含详细的中间步骤和最终结果。

## 关联脉络

- **上游依赖**
  - [[支撑该方法的定理]]
- **下游推导**
  - [[该方法适用的典型场景]]
- **双链引用**
  - 在 [[所属MOC]] 中被引用
```

## 各节写作要求

### `> [!info] 方法：[名称]`

- **内容**：一句话归纳——方法名 + 解决什么问题 + 核心思路
- **示例**："用于通过通项比值判断正项级数敛散性的方法。核心思路是将级数与等比级数进行间接比较。"
- **注意**：不要在此处展开步骤，步骤放在独立的 `## 方法步骤` 节

### `## 适用条件`

- **内容**：使用该方法前必须验证的所有前提条件
- **格式**：无序列表 `- `
- **重要性**：这是方法的"安全边界"——如果条件不满足而强行套用，结论无效
- **示例**：比值判别法的适用条件为 "正项级数" 且 "极限存在（或为 +∞）"

### `## 方法步骤`

- **格式**：有序列表 `1. `，按执行顺序编号
- **每步要求**：
  - 清晰描述操作
  - 每个操作后点明"为什么这样做"（背后的原理）
  - 涉及判定时，明确指出各分支的结论
- **禁止**：不可跳步、不可省略中间推理

### `> [!tip] 补充/注意`

- **与相似方法的对比**：如"比值法 vs 根值法"的区别和适用场景
- **常见错误**：如"当 ρ = 1 时不能得出任何结论，必须改用其他方法"
- **技巧提示**：如"遇到含 n! 的级数优先尝试比值法"

### `> [!example]- 例题`（可选但强烈建议）

- **折叠**：使用 `-` 后缀折叠
- **选取**：选择能体现方法"典型用法"和"易错点"的例题
- **展示**：完整计算过程，含所有中间步骤、推导依据和最终结论
- **数量**：1-2 道例题即可，重点是质量而非数量

### `## 关联脉络`

- **上游**：支撑该方法的理论定理
- **下游**：该方法能解决的典型问题类型
- **对比**：`[[替代方法]]` 用于失效情形

## 方法类 vs 定理类的区分

| 维度 | 方法类 | 定理类 |
|------|--------|--------|
| 标题 | "方法：XXX" | "定理/公理：XXX" |
| 核心内容 | 操作步骤 + 适用条件 | 命题陈述 + 证明 |
| 是否有证明 | 无（引用定理证明其正确性） | 有（完整证明） |
| 折叠节 | 例题（`[!example]-`） | 证明（`[!quote]-`） |
| 典型例子 | 比值判别法步骤、换序积分步骤 | 比值判别法定理、Fubini 定理 |

## 质量检查清单

- [ ] YAML `type` 为 `方法`
- [ ] 首段为 `> [!info] 方法：[名称]` Callout
- [ ] 适用条件完整列出
- [ ] 步骤使用有序列表，严格按执行顺序
- [ ] 步骤中解释了"为什么这样做"
- [ ] 包含易错点提示
- [ ] （建议）包含例题 Callout
- [ ] 关联脉络含上下游双链
- [ ] 全文数学符号用 LaTeX 包裹
- [ ] 无编号化名称

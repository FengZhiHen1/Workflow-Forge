# 定理类原子笔记写作规范 (Theorem Note Specification)

## 适用分类

YAML `type: 定理`，Callout `> [!info] 定理/公理：[名称]`。

> **公理**（Axiom）共用此规范：YAML type 统一为 `定理`，Callout 标题写为 `定理/公理：[名称]`。

## 内容布局（必须按此顺序）

```markdown
---
aliases:
course: {课程名}
type: 定理
status: 待整理
mastery: {1-5}
date_created: YYYY-MM-DD
tags:
  - 学习笔记
---
# {学术描述性名称}

> [!info] 定理/公理：{名称}
> 定理的完整陈述。所有条件、结论必须完备，符号使用 $\boldsymbol{加粗}$ 与 $\mathrm{直体}$。
> $$ 核心公式（如有） $$

> [!tip] 核心思路
> （可选）用一句话说明证明思路或定理在逻辑链中的角色。

> [!quote]- 证明
> 详细的数学推导。
> 1. 第一步...
> 2. 第二步...
> $$ 结论公式 $$ 证毕。

## 理解与细节
- 几何/物理直观
- 定理成立的前提条件逐一分析
- 条件放宽会怎样（反面说明）
- 与其他定理的关系
- 常见误用

## 关联脉络

- **上游依赖**
  - [[前置定义]]
  - [[依赖的前设定理]]
- **下游推导**
  - [[直接推论]]
  - [[依赖此定理的下游定理]]
- **双链引用**
  - 在 [[所属MOC]] 中被引用
```

## 各节写作要求

### `> [!info] 定理/公理：[名称]`
- **位置**：紧接 H1 标题之后
- **内容**：定理的完整陈述，**所有**条件必须列全（不可遗漏任何前提）
- **格式**：条件用"若/设/如果"引出，结论用"则/那么/即"引出
- **符号**：向量/变量用 `$\boldsymbol{}$`，算子用 `$\mathrm{}$`

### `> [!tip] 核心思路`（可选）
- **用途**：为复杂的定理提供一个"一句话总结"，帮助读者把握证明方向
- **示例**："将级数收敛问题转化为部分和数列的 Cauchy 收敛问题"
- **注意**：简单定理可省略，但较长的证明建议保留

### `> [!quote]- 证明`
- **折叠**：必须使用 `-` 后缀折叠
- **结构**：区分"必要性"和"充分性"（对于充要条件定理），分别标注
- **步骤**：使用有序列表 `1. ` 分步，每步后给出理由
- **引理使用**：若引用了中间引理，用 `（[[引理名]]）` 标注来源

### `## 理解与细节`
- **几何直观**：如果定理有几何背景，给出图示描述（用文字）
- **条件逐一分析**：每个前提条件的必要性——如果去掉会怎样？给出反例或说明
- **与等价命题的关系**：如果该定理与某命题等价（如确界原理 ↔ 单调有界定理），明确指出
- **常见误用**：
  - 条件记反（必要/充分条件混淆）
  - 使用前提未验证就开始套用

### `## 关联脉络`
- **上游依赖**：该定理证明中引用的所有前置命题
- **下游推导**：该定理的所有推论和依赖此定理的其他命题
- **注意**：关联脉络必须与 MOC 中的从属关系一致

## 质量检查清单

- [ ] YAML `type` 为 `定理`
- [ ] 首段为 `> [!info] 定理/公理：[名称]` Callout
- [ ] 定理陈述完整，条件和结论不遗漏
- [ ] 证明使用 `> [!quote]-` 折叠
- [ ] 理解段分析了每个条件的必要性
- [ ] 关联脉络含上下游双链
- [ ] 全文数学符号用 LaTeX 包裹
- [ ] $\boldsymbol{}$ 用于变量/向量，$\mathrm{}$ 用于微分/常数
- [ ] 无编号化名称

# 定义类原子笔记写作规范 (Definition Note Specification)

## 适用分类

YAML `type: 定义`，Callout `> [!abstract] 定义：[名称]`。

## 内容布局（必须按此顺序）

```markdown
---
aliases:
course: {课程名}
type: 定义
status: 待整理
mastery: {1-5}
date_created: YYYY-MM-DD
tags:
  - 学习笔记
---
# {学术描述性名称}

> [!abstract] 定义：{名称}
> 严格而精确的定义表述。所有数学符号使用 $\boldsymbol{加粗}$ 与 $\mathrm{直体}$。
> $$ 核心公式（如有） $$

## 核心概念与结构
（可选，当定义涉及多个子概念时使用，用 ### 拆分子概念）

## 理解与细节
> [!tip] 补充/注意
> - 直观理解
> - 常见误解澄清
> - 与其他定义的对比

## 关联脉络

- **上游依赖**
  - [[前置定义]]
- **下游推导**
  - [[依赖此定义的性质/定理]]
- **双链引用**
  - 在 [[所属MOC]] 中被引用
```

## 各节写作要求

### `> [!abstract] 定义：[名称]`
- **位置**：紧接 H1 标题之后，全文第一段正文
- **内容**：定义的精确表述。首选教材原句，不丢失任何条件
- **符号**：关键数学对象用 `$\boldsymbol{}$`，特殊符号用 `$\mathrm{}$`
- **禁止**：在此 Callout 中混入"理解"、"补充"等非定义内容

### `## 核心概念与结构`（可选）
- **用途**：当定义包含多个紧密关联的子概念（如"收敛"与"发散"成对出现，"部分和"与"余和"共同构成级数的结构）时使用
- **拆分**：每个子概念用 `###` 标题单独说明
- **注意**：简单定义可不设此节

### `## 理解与细节`
- **核心价值**：连接抽象定义与直观理解
- **内容要点**：
  - 为什么这样定义？（动机）
  - 定义的隐含等价形式
  - 与读者直觉可能冲突的地方
  - 常见误用（如必要条件误当充分条件）
  - 反例说明（如有）

### `## 关联脉络`
- **上游依赖**：标记该定义依赖的前置概念（数列极限、集合论基础等）
- **下游推导**：标记由该定义出发的所有后续命题
- **双链引用**：标注 MOC 或其他引用源

## 质量检查清单

- [ ] YAML `type` 为 `定义`
- [ ] 首段为 `> [!abstract] 定义：[名称]` Callout
- [ ] 定义表述精确无歧义，不丢失条件
- [ ] 理解段包含直观解释和常见误解
- [ ] 关联脉络含上下游双链
- [ ] 全文数学符号用 LaTeX 包裹
- [ ] 无编号化名称
- [ ] 正文标点使用中文全角

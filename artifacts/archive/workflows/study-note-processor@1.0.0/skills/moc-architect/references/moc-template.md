# MOC 输出模板 (MOC Output Template)

> 此模板被 `moc-architect` Skill 使用。运行时的变量（如 `{course}`、`{X.Y}`、`{H2模块名}`、`{原子点列表}` 等）由 Skill 根据输入 Markdown 和领域配置动态填充。

---

## 模板：节级 MOC（`_MOCs/MOC-X.Y {节名}.md`）

```markdown
---
aliases:
course: {course}
type: 节MOC
status: 待整理
mastery: 1
date_created: {date_created}
tags:
  - 学习笔记
---
# MOC-{X.Y} {节名}

{for each H2 module:}

## {H2模块名}

> [!abstract]- 逻辑脉络图景
> ### 1. 核心动机
> {核心动机：为什么要引入这些概念？解决什么痛点？}
> 
> ### 2. 逻辑推演与直观视角
> {逻辑推演：知识点如何从 A 演化到 B。穿插使用 **加粗** 和 ==高亮== 核心逻辑。}
> > [!warning] 易错点/重难点
> > - {易错点 1}
> > - {易错点 2}
> 
> ### 3. 逻辑架构图
> ```mermaid
> graph TD
>     {Mermaid 节点和边}
> ```
> 
> ---
> **🚩 下一步挑战**：{承前启后，引出下一 H2 模块或下一节}

{原子点列表，使用 4 空格缩进表达逻辑从属}
{一级原子点用 `- [["..."]]` 格式，从属原子点缩进 4 空格}
- [[{原子点名称 1}]]：{15-30 字概述，点破其逻辑作用}
    - [[{从属原子点名称}]]：{15-30 字概述}
- [[{原子点名称 2}]]：{15-30 字概述}

{end for}
```

## 变量说明

| 变量 | 来源 | 说明 | 示例 |
|------|------|------|------|
| `{course}` | 用户指定或从书名推断 | 课程/教材名 | `高等微积分` |
| `{X.Y}` | 从 PDF / Markdown 章节目录提取 | 章节编号 | `1.1` |
| `{节名}` | 从 PDF / Markdown H1 提取（去除编号） | 纯描述性节名 | `常数项级数的概念与基本性质` |
| `{date_created}` | 系统日期 | YYYY-MM-DD 格式 | `2026-05-13` |
| `{H2模块名}` | 从 Markdown H2 或逻辑拆解得出 | 纯文本，无编号 | `常数项级数的概念与基本性质` |
| `{核心动机}` | AI 分析 Markdown 内容生成 | 2-3 句 | 见真实 MOC 示例 |
| `{逻辑推演}` | AI 分析 Markdown 内容生成 | 3-5 句，含加粗/高亮 | 见真实 MOC 示例 |
| `{Mermaid 节点和边}` | AI 按 Mermaid 规范生成 | 节点名 = 双链名 | 见下方 Mermaid 规范 |
| `{原子点列表}` | AI 从 Markdown 提取并分类 | 含概述和从属关系 | 见下方原子点规范 |

## Mermaid 节点与边规范

### 节点形状
| 知识点类别 | 形状 | Mermaid 语法 | 示例 |
|-----------|------|-------------|------|
| 定义 | 矩形 | `A[["双链名"]]` | `A[["常数项无穷级数定义"]]` |
| 定理 / 公理 | 菱形 | `B{"双链名"}` | `B{"级数收敛的Cauchy准则定理"}` |
| 性质 / 引理 / 推论 | 矩形 | `C[["双链名"]]` | `C[["收敛级数的线性性质"]]` |
| 方法 | 矩形 | `D[["双链名"]]` | `D[["任意项级数判别步骤方法论"]]` |
| 反例 | 矩形 | `E[["双链名"]]` | `E[["调和级数发散的反例"]]` |

### 边样式
| 关系类型 | 样式 | Mermaid 语法 | 示例 |
|----------|------|-------------|------|
| 直接推导 / 充分条件 | 实线箭头 | `-->` | `A --> B` |
| 等价关联 / 必要条件 | 虚线箭头 | `-.->` | `D -.-> E` |
| 带标签的边 | 实线 + 文本 | `-->|文本|` | `A -->|部分和构造| B` |

### 关键约束
1. **节点文本**：与 `[[双链名称]]` 严格一致
2. **半角双引号**：当节点文本包含 `!`、`(`、`)`、`[`、`]`、`|` 等特殊字符时，`[[ ]]` 已由 `"` 包裹，务必注意。节点引用格式为 `A[["节点名"]]`
3. **节点数**：每个 H2 模块的 Mermaid 图节点数控制在 5-12 个，避免过于拥挤
4. **起点与终点**：图应有明确的逻辑起点（通常是定义）和关键终点（通常是核心定理）

## 原子点命名规范

### 命名格式
```
{学术描述性名称}{身份后缀}
```

### 身份后缀
| 类别 | 后缀 | 示例 |
|------|------|------|
| 定义 | `定义` | `常数项无穷级数定义` |
| 定理 | `定理` | `级数收敛的Cauchy准则定理` |
| 公理 | `定理`（与定理共用后缀） | `确界原理定理` |
| 性质 | `性质` | `收敛级数的线性性质` |
| 引理 | `定理` | `Leibniz判别法定理` |
| 推论 | `推论` | `单调有界推论收敛` |
| 方法 | `方法论` / `方法` | `任意项级数判别步骤方法论` |
| 反例 | `的反例` | `调和级数发散的反例` |

### 命名铁律
1. **严禁编号**：禁止 `性质 1.1`、`Definition 1` 等形式
2. **学术描述性**：名称应准确反映数学内涵，而非序号
3. **唯一性**：同一 Vault 内双链名必须唯一（通过学术名称自然保证）
4. **后缀一致性**：名称后缀必须与 YAML `type` 和 Callout 类型一致

## 原子点列表格式

### 层级规则
- **一级列表**（`- `）：核心定义、独立定理、基本性质
- **二级列表**（4 空格缩进）：直接推论、从属引理、特定反例
- **三级及以上**：极罕见，不建议（若需要，重新审视 H2 模块划分是否合理）

### 概述要求
每个原子点后跟 `：{15-30 字概述}`：
- **定义类**：点明其量化的核心数学直观
- **定理类**：点明其在逻辑链中的"状态转换"或"判定功能"
- **性质类**：点明其描述的数学行为
- **方法类**：点明其解决的问题类型
- **反例类**：点明其证伪的命题

**禁止**：复读双链名称本身作为概述。

### 示例（取自真实 MOC）

```markdown
- [[常数项无穷级数定义]]：将数列各项依次相加的表达式，核心是将其敛散性转化为部分和数列的极限。
    - [[级数的部分和与余和定义]]：$S_n$ 是收敛判定的载体；$r_n$ 刻画收敛时的逼近误差。
- [[级数收敛与发散定义]]：若 $\lim S_n$ 存在有限则收敛，否则发散。这是整个级数理论的逻辑原点。
- [[级数收敛的Cauchy准则定理]]：收敛的充要条件是任意远处片段和的绝对值可任意小。它不依赖于和的值，是理论证明的基石。
```

## 书级 MOC 格式（`00-{course}-MOC.md`）

```markdown
---
aliases:
  - {course}
course: {course}
type: 书MOC
status: 待整理
mastery: 1
date_created: {date_created}
tags:
  - 学习笔记
---
# 00-{course}-MOC

## 第 {X} 章 {章名}

### [[MOC-{X}.1 {节名}]]
### [[MOC-{X}.2 {节名}]]
...

## 第 {X2} 章 {章名2}

### [[MOC-{X2}.1 {节名}]]
...
```

**书级 MOC 更新规则**：
- 每次运行新增一节 MOC 时，检查 `00-{course}-MOC.md` 是否已存在
- 若不存在：根据 PDF 目录信息创建完整框架（全章全节占位）
- 若已存在：确认当前节的 `[[MOC-X.Y 节名]]` 已出现在对应章节下（不存在则追加）

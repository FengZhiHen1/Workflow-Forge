# Reference：输出文件模板与命名规范

本文件定义 model-architect 的全部输出文件模板。Skill 主体中仅保留文件清单与引用说明，**详细模板内容以此文件为准**。

---

## 文件组织方式

每个小问的模型选型产出拆分为 **N+1 个文件**（N = 方案数量）：

| 序号 | 文件路径 | 说明 |
|:---|:---|:---|
| 1–N | `VERSION_DOCS/P2-模型选型_方案{N}_[模型简称].md` | 单个候选方案的完整说明 |
| N+1 | `VERSION_DOCS/P2-模型选型_对比总结.md` | 全方案对比矩阵 + 综合对比总结 + 最终选型建议 |

> 命名规范：`方案{N}` 中的 N 使用两位数字，如 `方案01`、`方案02`；`[模型简称]` 取模型核心名，如 `线性回归`、`神经网络`、`多目标优化`。

## 1. 总体原则

- **`.claude/`**：工作流基础设施，**纳入版本控制**。存放静态规范、契约、脚本。
- **`.agent/`**：工作流运行时状态，**加入 `.gitignore`**。存放动态实例、Message 池、备份。
- **`.tmp/`**：工作流过程产物草稿，**加入 `.gitignore`**。存放待确认的文档草稿、附件。
- **业务目录**（`workspace/`、`results/`、`docs/` 等）：**不在本规范范围内**，由具体 Skill 自主管理。

## 3. 目录职责与权限

| 目录 | 写入者 | 读取者 | 说明 |
|------|--------|--------|------|
| `.claude/workflows/` | 人工/版本控制 | 编排器、Skill | Reference 工作流定义，只读 |
| `.claude/skills/` | Skill 作者 | SubAgent、编排器 | Skill 定义与专用契约 |
| `.claude/scripts/` | 基础设施维护者 | SubAgent、编排器 | 写入脚本、校验脚本、哈希脚本 |
| `.claude/contracts/` | 基础设施维护者 | SubAgent | 通用契约 |
| `.agent/workflows/instances/` | **编排器独占** | 编排器 | 动态状态机，SubAgent 禁止触碰 |
| `.agent/workflows/registry.json` | **编排器独占** | 编排器 | 活跃实例索引 |
| `.agent/messages/` | SubAgent（经脚本）、编排器（状态推进） | 编排器 | 通信协议层 |
| `.agent/backups/` | 编排器 | 编排器 | 回退锚点快照 |
| `.tmp/<instance>/<message>/` | SubAgent | 编排器 | 文档草稿、过程产物 |

## 5. 路径标准化规则

所有规范文件中的路径引用遵循：

1. **以项目根为基准**：使用相对路径，无 `./` 前缀，无 `../`，无 `//`。
2. **统一分隔符**：`/`（即使在 Windows 环境也由脚本统一处理）。
3. **目录结尾**：仅目录路径以 `/` 结尾，文件路径不以 `/` 结尾。

## 6. 与已有规范的衔接

- **Workflow 规范**：Reference 文件路径更新为 `.claude/workflows/<workflow_id>@<version>.md`；Instance 和 Registry 路径保持不变。
- **Skill 规范**：通用契约路径更新为 `.claude/contracts/common.md`；Skill 专用契约仍在 `.claude/skills/<skill_id>/references/` 下。
- **Message 规范**：写入脚本路径更新为 `.claude/scripts/write_message.py`；Message 存储路径保持不变。

# 项目定位

---

## 这是什么

一个面向**开发者**的 AI 工作流框架。开发者用 YAML 声明工作流（stages + edges + 并发规则），框架自动将工作流实例化为可调度的任务链，在主 Agent 的指挥下推进 SubAgent 执行。

框架跨 Agent 应用可移植。它不绑定于某一特定平台，而是在宿主 Agent 应用之上运行。消费者项目中采用 `.claude/` 作为默认工作流目录，是因为该路径已成多个主流编码 Agent 加载 Skill 的事实标准——它不是绑定，而是顺应共识。

---

## 谁用它

**开发者。** 使用 AI Agent 辅助编程、但需要将多阶段复杂任务结构化为可控流水线的人。

不是终端用户。没有 Web 界面，没有多租户，没有审批流。一切通过命令行和 AI 对话完成。

---

## 它不是什么

- **不是自动写代码的机器人。** 工作流执行的最终产物是否写入仓库由开发者决定。
- **不是 CI/CD 替代品。** 不构建、不部署、不监控线上服务。
- **不是 SaaS 平台。** 不做多用户、不做权限体系、不做计费。
- **主 Agent 不是工作流系统自创的独立智能体。** 它就是承载本框架的 Agent 应用（如 Claude Code）自身。
- **wfctl 不是独立服务。** 它是主 Agent 手中的命令行工具，不在架构中作为对等实体存在。

# 消费者项目目录规范 v3.0.0

> 本文档定义消费者项目（即使用工作流框架的项目）中的目录结构。
> 生产车间（本仓库）的目录规范见 `workshop/specs/目录规范.md`。

---

## 1. 总体原则

- **`.claude/`**：工作流基础设施，纳入版本控制。存放静态规范、契约、脚本、工作流定义、Skill 定义。
- **`.agent/`**：工作流运行时状态，加入 `.gitignore`。存放实例状态机、Message 池、审计日志、子工作流。
- **`.tmp/`**：工作流临时产物，加入 `.gitignore`。存放 git worktree 工作副本。
- **业务目录**（`src/`、`docs/`、`tests/` 等）：不在本规范范围内，由具体 Skill 自主管理。

---

## 2. 目录结构

```
项目根目录/
├── .gitignore
├── .claude/                                # 基础设施 → 版本控制
│   ├── contracts/
│   │   ├── common.md                       # 通用工作流契约（硬禁令）
│   │   ├── input.md                        # 通用输入契约
│   │   └── output.md                       # 通用输出契约
│   ├── workflows/                          # 工作流定义
│   │   └── <workflow_id>/                  # 每个工作流一个目录
│   │       ├── WORKFLOW.md                 # 人类可读：名称、概览、Mermaid 流程图
│   │       └── WORKFLOW.yaml               # 机器规范：stages、edges、并发规则
│   ├── skills/                             # Skill 定义
│   │   └── <skill_id>/
│   │       ├── SKILL.md                    # Skill 主文件（YAML frontmatter + 正文）
│   │       ├── references/                 # [可选] 专用契约及参考
│   │       └── scripts/                    # [可选] Skill 辅助脚本
│   └── scripts/                            # 基础设施脚本
│       └── wfctl/                          # wfctl 机械调度程序包（含 message write、状态校验等全部机械操作）
├── .agent/                                 # 运行时状态 → .gitignore
│   └── instances/
│       └── <instance_id>/                  # 每个工作流实例一个目录
│           ├── instance.json               # 实例状态机
│           ├── messages/                   # Message 通信池
│           │   └── <message_id>.json
│           ├── logs/                       # 审计日志
│           │   ├── timeline.jsonl          # 状态流转全记录
│           │   ├── deviation.jsonl         # 偏差记录（非标准行为）
│           │   └── stage_history.jsonl     # stage 历史
│           └── children/                   # 子工作流实例
│               └── <child_id>/             # 同上结构
└── .tmp/                                   # 临时产物 → .gitignore
    └── worktrees/                          # git worktree 工作副本
        ├── instance-<instance_id>/         # 实例级 worktree
        ├── stage-<instance_id>-<s_id>/     # 并发 stage 级 worktree
        └── stage-<instance_id>-<s_id>#<n>/ # parallel 拆分 worktree
```

## 3. 目录职责与权限

| 目录 | 写入者 | 读取者 | 说明 |
|------|--------|--------|------|
| `.claude/workflows/` | 人工 / workflow-puller | wfctl | 工作流定义，只读 |
| `.claude/skills/` | Skill 作者 / workflow-env-init | SubAgent、主 Agent | Skill 定义与专用契约 |
| `.claude/scripts/` | 基础设施维护者 | SubAgent、wfctl | 调度程序与辅助脚本 |
| `.claude/contracts/` | 基础设施维护者 | SubAgent（自行读取） | 通用契约 |
| `.agent/instances/<id>/instance.json` | **wfctl 独占** | wfctl | 动态状态机，SubAgent 禁止触碰 |
| `.agent/instances/<id>/messages/` | SubAgent（经 wfctl message write） | wfctl（消费时） | 通信协议层 |
| `.agent/instances/<id>/logs/` | wfctl | 开发者 | 审计日志 |
| `.agent/instances/<id>/children/` | wfctl | wfctl | 子工作流实例 |
| `.tmp/worktrees/` | wfctl、SubAgent | wfctl、SubAgent | 隔离工作副本 |

---

## 4. wfctl 的角色

wfctl（`python -m wfctl`）是安装在 `.claude/scripts/wfctl/` 下的 Python 包。它是所有文件系统操作的唯一入口：

| 操作 | 执行者 |
|------|--------|
| 创建/读取/更新 instance.json | wfctl |
| 写入/扫描/消费 Message | wfctl |
| 创建/合并/清理 worktree | wfctl |
| 追加 timeline / deviation | wfctl |
| 打/删 git 锚点 | wfctl |

主 Agent 不直接操作文件系统，始终通过 wfctl 命令间接操作。SubAgent 仅通过 `wfctl message write` 和 `wfctl identity` 与主仓库通信。

---

## 5. 初始化流程

消费者项目通过 `workflow-env-init` Skill 一键初始化：

1. 创建 `.claude/` 下所有目录结构
2. 从生产车间拉取契约文件、基础设施脚本、全局 Skill
3. 安装 wfctl 到 `.claude/scripts/wfctl/`
4. 创建 `.agent/instances/` 和 `.tmp/worktrees/` 运行时目录
5. 更新 `.gitignore`

工作流定义由 `workflow-puller` 按需拉取，不在初始化时写入。

---

## 6. `.gitignore` 模板

```gitignore
# 运行时状态
.agent/

# 临时产物
.tmp/

# Python
__pycache__/
*.pyc
```

> `.claude/` 纳入版本控制，**不**在 `.gitignore` 中。

---

## 7. 路径标准化规则

1. 以项目根为基准：相对路径，无 `./` 前缀，无 `../`，无 `//`
2. 统一分隔符：`/`（Windows 环境由 wfctl 统一处理）
3. 目录结尾：仅目录路径以 `/` 结尾，文件路径不以 `/` 结尾

---

## 8. 与旧版（v2）的差异

| 维度 | v2 | v3 |
|------|----|----|
| 实例路径 | `.agent/workflows/instances/<id>.json` | `.agent/instances/<id>/instance.json` |
| 消息路径 | `.agent/messages/YYYY-MM-DD/<id>.json` | `.agent/instances/<id>/messages/<id>.json` |
| 实例索引 | `.agent/workflows/registry.json` | 无（wfctl status 动态扫描） |
| 备份 | `.agent/backups/<id>/<ts>.tar.gz` | 无（git reflog 30 天恢复） |
| 临时产物 | `.tmp/<instance>/<message>/`（草稿） | `.tmp/worktrees/`（git worktree） |
| 调度器 | workflow-orchestrator Skill | wfctl 命令行工具 |
| 工作流路径 | `.claude/workflows/<id>@<ver>/` | `.claude/workflows/<id>/` |
| Skill 格式 | `[WORKFLOW_CONFIG]` 代码块 | YAML frontmatter，工作流信息由 prompt 注入 |
| 契约读取 | 主 Agent 转述 | SubAgent 自行读取 |

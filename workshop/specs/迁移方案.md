# 仓库结构迁移方案 v1.0.0

---

## 〇、背景

本仓库从 v2 规范体系升级到 v3.0.0 规范体系。旧目录结构（`docs/`、`results/`、`reference/`）需迁移到新结构（`workshop/`、`artifacts/`），与 v3 规范对齐。

---

## 一、`docs/` 目录

| 文件 | 操作 | 目标路径 |
|------|------|---------|
| `目录规范v2.md` | 重构为 v3 消费者项目目录规范 | `workshop/specs/细节设计/消费者项目目录规范.md` |
| `工作流思想.md` | 删除（已存在于 `workshop/specs/工作流思想.md`） | — |
| `workflow规范v2.md` | 归档 | `workshop/archive/workflow规范v2.md` |
| `skill规范.md` | 归档 | `workshop/archive/skill规范.md` |
| `message规范.md` | 归档 | `workshop/archive/message规范.md` |
| `MinerU_API文档.md` | 迁移（外部工具参考） | `workshop/reference/MinerU_API文档.md` |
| `归档/` | 合并 | `workshop/archive/` |

操作后 `docs/` 清空并删除。

---

## 二、`results/` 目录

| 内容 | 操作 | 目标路径 |
|------|------|---------|
| `workflows/`（11 个工作流） | 归档（v2 格式，后续单独升级） | `artifacts/archive/workflows/` |
| `skills/`（5 个 Skill） | 迁移（现行资产） | `artifacts/skills/` |
| `contracts/` | 删除（与 `artifacts/contracts/` 重复） | — |
| `scripts/write_message.py` | 迁移 | `artifacts/scripts/write_message.py` |
| `scripts/validate_instance.py` | 迁移 | `artifacts/scripts/validate_instance.py` |
| `wfctl-审查报告.md` | 删除（临时文件） | — |

操作后 `results/` 清空并删除。

---

## 三、`reference/` 目录（仓库根）

| 内容 | 操作 | 目标路径 |
|------|------|---------|
| `skills/`（1.md, 2.md, 3.md, DESIGN.md） | 迁移 | `workshop/reference/skills/` |
| `templates/` | 迁移，与 `workshop/templates/` 去重 | `workshop/templates/` |
| `编程笔记设计.md` | 迁移 | `workshop/reference/编程笔记设计.md` |

操作后 `reference/`（仓库根）清空并删除。

---

## 四、不动项

| 路径 | 原因 |
|------|------|
| `workshop/specs/` | 已是 v3 规范 |
| `artifacts/contracts/` | 现行契约 |
| `artifacts/scripts/wfctl/` | wfctl 实现 |
| `.claude/skills/` | 车间自用 Skill，不参与分发 |
| `.agent/` | 运行时目录（gitignore） |
| `.tmp/` | 临时目录（gitignore） |
| `.gitignore` | 保持不变 |

---

## 六、执行步骤

1. 重构消费者项目目录规范并写入 `workshop/specs/细节设计/`
2. 创建缺失目录（`workshop/archive/`、`workshop/reference/`、`artifacts/archive/workflows/`、`artifacts/workflows/`、`artifacts/skills/`）
3. 迁移文件（按上述映射）
4. 删除空目录（`docs/`、`results/`、`reference/`）
5. 运行 wfctl 测试确认无回归

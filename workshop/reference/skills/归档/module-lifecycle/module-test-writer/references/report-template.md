# 测试报告输出模板

> 本模板定义了 module-test-writer 生成的测试报告的完整格式。
>
> **核心理念**：这不是一份"我完成了多少工作"的报告，而是一份"这份验收测试能否有效保护实现不被回归破坏"的评估。
>
> 报告保存路径：`docs/testing-design/{module_id}/test-report.md`

## 7. 诚实声明

本测试套件由 module-test-writer 生成：

1. 本测试套件基于落地规范中的契约编写，同时参考了实现代码的内部逻辑。
2. 测试未因运行结果而修改断言期望值。
3. 若存在实现与契约不符的情况，已在「实现差异记录」中标注。
4. 趋绿扫描结果为客观 AST 分析输出，已用于自检但非阻塞交付。
5. 所有 mock 均标注了被 mock 模块和替换条件。
